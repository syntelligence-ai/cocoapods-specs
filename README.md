# Syntelligence CocoaPods specs

The CocoaPods spec repository for Syntelligence's SDKs. Add it as a source in your Podfile,
alongside the CDN:

```ruby
source 'https://github.com/syntelligence-ai/cocoapods-specs.git'
source 'https://cdn.cocoapods.org/'
```

Each pod's podspecs are written by the Release workflow of the SDK that ships it; they are not
edited by hand.
